# 0001 - Use JUCE 9.0.5 under AGPLv3

Date: 2026-11-17. Status: accepted.

## Context
The master plan (written from memory) names JUCE 8. The phase 0 licence check found that the
current JUCE release is 9.0.5. JUCE 9 keeps the same dual licence (AGPLv3 or paid commercial).

## Decision
Use JUCE 9.0.5, pinned by tag in `cmake/MxjDependencies.cmake`, under AGPLv3 (free).

## Consequences
- Newer platform fixes; JUCE 9 also bundles the ASIO SDK headers (GPLv3 option) and Opus
  reading and writing, which removes two separate downloads.
- `Drawable` now lives in `juce_graphics`; SVG is loaded with `Drawable::createFromSVGString`.
- Upgrading JUCE later is a deliberate change: bump the tag, read `BREAKING_CHANGES.md`, run CI.
